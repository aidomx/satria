# Satria v0.2.4 — A New Identity

Formerly known as rbot (Rupa Builder Of Target).

Satria v0.2.4 marks an important milestone: rbot has officially been renamed to Satria.

This release introduces a new identity while preserving the project's original philosophy:

"A Simple Builder for You."

The name has changed, but the mission remains the same: to provide a lightweight, fast, and declarative build system for C and C++ developers.

# What's New

## From rbot to Satria

The project is now officially known as Satria.

This rebranding reflects the project's evolution beyond its original identity.

The new name represents a fresh chapter in development, with continued emphasis on simplicity, performance, portability, and build correctness.

# Build System Improvements

Development continues to focus on:

- Efficient single-project and workspace builds.
- Content-based incremental compilation.
- Static and shared library generation.
- Workspace dependency management.
- Binary resource embedding and release packaging.
- Compiler and linker portability.

# Performance & Reliability

Satria continues to prioritize efficient builds without sacrificing correctness.

Our guiding principle remains simple:

Different strategies are welcome, but required build operations must never be skipped just to achieve better benchmark results.

Performance improvements should come from reducing unnecessary overhead, not producing incomplete builds.

# Feedback & Contributions

Satria is an independent open-source project developed through continuous experimentation and real-world testing.

Bug reports, suggestions, technical discussions, and contributions are always welcome.

Thank you to everyone who has followed the project since its rbot days.
