# satria Documentation

**A simple builder for you.**

Documentation package for satria. This archive contains documentation only; it does not contain satria source code.

## Contents

- `docs/guide/` — getting started, Buildfile, incremental builds, workspace, releases, packaging, platform usage, profiling
- `docs/reference/` — CLI and Buildfile reference
- `docs/design/` — design philosophy and architecture notes
- `docs/benchmark/` — benchmark methodology and interpretation

## Version scope

The implementation reference in this package is based on **satria v0.2.4**. Later design discussions are explicitly marked as proposed direction and should not be read as features guaranteed by the release.
