## [x] Packaging `pack.*` — SELESAI & terverifikasi

### Desain (disetujui user)
- `.deb` dirakit **manual**: header ar ditulis di C, staging `control.tar.gz` +
  `data.tar.gz` dibuat via `tar`+`gzip` shell — **tanpa `dpkg-deb`**, portabel
  sampai MSVC (asumsi: ar/tar/gzip tersedia; di Termux/proot semuanya ada).
- `pack.format = deb` **menambah** `.deb` di samping tarball (dua artefak),
  kecuali template output berakhiran `.deb` → mode deb-only.
- Pemetaan deb: tiap entri `pack.files` dipasang di `<install_prefix>/<entri>`
  (prefix default `/usr/local`, bisa dioverride `pack.deb.prefix`).

### Spec
- Sumber section `pack`: mandiri di Buildfile ATAU key bare via
  `projects.<n>.pack as pack` di workspace (prefix `projects.<n>.` di-strip saat
  sintesis).
- `pack.files` / `pack.output` menandai pack aktif (`pack.requested`).
- Proyek tanpa sources → otomatis `output.binary=false` (configFinalize);
  proyek binary tetap bisa pack sekaligus (hybrid).
- Template nama: `{name} {version} {os} {arch}`.
- Nama `.deb`: ekstensi tar dikenal (`.tar.gz/.tar.xz/.tar.bz2/.tgz/.tar`)
  diganti `.deb`.
- `pack.compress`: eksplisit `gzip|none|xz|bz2` (`"bzip2"` → `"bz2"`) atau dari
  ekstensi output.
- `pack.checksum`: sha256 saja; file `<hex>  <basename>` (2 spasi, kompatibel
  `sha256sum -c` — terverifikasi cocok coreutils).
- `pack.format`: `tar|none|deb` (lain → error).
- Freshness: rebuild hanya bila entri `pack.files` terbaru (folder di-walk
  rekursif + mtime direktori ikut dihitung) > mtime artefak; aturan sama untuk
  file checksum.
- Mode file deb: `0755` untuk komponen pertama `bin/` atau `*.so`, ATAU bit +x
  sumber dipertahankan (via `fsGetMode`).
- `clean` TIDAK menyentuh `dist/` (bisa dirujuk `embedded.*` proyek lain) tapi
  menghapus staging `.rbot/pack`.
- SHA-256 murni C (FIPS 180-4), modul `src/pack/pack_sha256.c`.
- ar archive: `!<arch>\n` + member `debian-binary` (`"2.0\n"`),
  `control.tar.gz`, `data.tar.gz`; header member 60 byte
  `%-16.16s%-12ld%-6s%-6s%-8s%-10lld\`\n`; data ganjil di-pad `\n`.
- Deb control: `Package`/`Version`/`Architecture`
  (host-derived `amd64/arm64/i386/riscv64/armhf/all`, override
  `pack.deb.architecture`)/`Maintainer` (default
  `rbot <rbot@localhost>`)/`Installed-Size`/`Description` (default `pack.name`).
- Config cache **v5→v6** (semua field PackConfig diserialisasi).
- `packSetStr` melepas kutip ganda pembuka/penutup.
- Routing configApply: bare key top-level
  `name/version/output/compress/checksum/format/files` → packApply; section
  `deb` → packApplyDeb; section `pack` sub `deb` → packApplyDeb;
  listForSection `pack` → pack.files.
